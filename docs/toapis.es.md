# Ruta opcional de imágenes con ToAPIs

La ruta Gemini existente no cambia. El nuevo script reutiliza el cargador de plantillas, consulta el precio de la Key y solo genera con `--live`. Guarda el ID de la tarea y no repite un POST incierto. Compatible con gpt-image-2 y gpt-image-2.5-flare, una imagen, 1K/2K/4K y proporciones 1:1/16:9/9:16. No incluye edición ni vídeo.

Prueba real del 29 de octubre de 2026: gpt-image-2, 1K, PNG descargado, $0.015 liquidados (3 créditos) para la Key probada. [Configuración y validación](toapis.md).
